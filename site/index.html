BON À SAVOIR

Les questions
qui restent.

Tout est dans le manuel ↗
Est-ce compatible avec mon board Kanban ?+

Oui. L’extension reprend le filtre et les colonnes de votre board Kanban. Ses objectifs viennent des Goals Atlassian. En Scrum, vous pouvez aussi utiliser les lignes du texte de l’objectif du sprint.

Faut-il reconfigurer tout le board ?+

Non. Les colonnes, les statuts et les types sont lus depuis Jira. Vous pouvez ensuite personnaliser les swimlanes et les cartes. Les réglages déjà partagés par votre équipe sont repris automatiquement.

Est-ce que mes droits Jira changent ?+

Non. Les actions restent soumises à vos permissions Jira. Les réglages partagés demandent le droit de modifier le board et les transitions suivent votre workflow.

Comment se font les mises à jour ?+

Chrome met automatiquement à jour l’extension depuis le Chrome Web Store. Un redémarrage du navigateur peut permettre d’appliquer une mise à jour en attente. Sur un navigateur géré par votre entreprise, les règles de votre administrateur s’appliquent.
